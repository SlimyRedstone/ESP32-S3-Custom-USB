Printed on the CDC serial port. The device reassembles transfers larger than one 64-byte packet, so the limit is the 512-byte JSON buffer.

Config

Contents of /config.json. Get reads it from the device, Set merges what you type back and saves it to SPIFFS. Partial objects are fine — absent keys keep their value.
